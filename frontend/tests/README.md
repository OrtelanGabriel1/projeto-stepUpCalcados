# Testes do frontend

Execute os testes a partir da pasta `frontend`:

```bash
npm test
```

O Jest gera automaticamente um relatório navegável em
`tests/reports/jest-report.html`, com o resultado de cada teste. Abra esse
arquivo no navegador para visualizar ou capturar a tela.

Para acompanhar os testes em modo interativo, use `npm run test:watch`. Para
gerar também os dados de cobertura, use `npm run test:coverage`.
